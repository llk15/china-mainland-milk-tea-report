# 中国大陆奶茶报告

把奶茶品牌公开发布的检验报告和营养信息，整理成可以直接浏览、筛选、排序和追溯的数据。

**在线浏览：** [中国大陆奶茶报告](https://llk15.github.io/china-mainland-milk-tea-report/)

## 这个仓库做什么

奶茶品牌开始公开越来越多的营养信息和检验报告，但这些资料往往分散在不同产品、不同规格和不同页面中，不容易横向比较。

这个仓库希望建立一份持续更新的公开索引：

- 收集品牌主动公开的饮品检验报告；
- 按产品、杯型、温度、糖度等规格整理数据；
- 提供热量、蛋白质、碳水、脂肪、咖啡因、茶多酚等指标的筛选和排序；
- 尽可能保留每条数据对应的原始报告链接；
- 同时提供网页、CSV 和 Excel，方便不同使用场景。

## 当前收录

首批数据来自霸王茶姬公开健康计算器：

- 98 款饮品；
- 1,756 条规格记录；
- 9 个饮品品类；
- 1,746 条记录带有原始检验报告链接；
- 数据更新至 2026-07-24。

后续计划继续收录其他在中国大陆运营、并公开检验报告或营养信息的奶茶品牌。

## 如何使用

打开[在线浏览页面](https://llk15.github.io/china-mainland-milk-tea-report/)，可以：

- 搜索饮品名称；
- 按品类、营养等级、杯型、温度和糖度筛选；
- 按热量、咖啡因、蛋白质、茶多酚、碳水等指标排序；
- 查看具体规格的完整营养数据；
- 在站内报告页查看品牌公开的原始检验报告。

需要进一步分析时，可以下载：

- [完整 CSV 数据](data/chagee/chagee_drinks.csv)
- [可筛选 Excel 数据](data/chagee/chagee_nutrition.xlsx)

## 数据来源与原则

当前数据来自[霸王茶姬健康计算器](https://qmproductcomput.bwcj.com/)。仓库只整理品牌已经公开的信息，不修改原始营养值，并尽量保留原报告地址和数据更新时间。

同一饮品在不同杯型、温度、糖度、茶底或奶底下可能有明显差异，因此本项目以“具体规格”为基本记录，而不是只展示一个产品平均值。

## 仓库内容

- `index.html` 与 `assets/`：交互式浏览页面；
- `data/chagee/`：霸王茶姬公开数据和网页数据；
- `scripts/`：数据采集、整理与网页数据生成脚本。

## 参与完善

欢迎通过 Issue 或 Pull Request 提交：

- 新的公开报告来源；
- 已下架、失效或更新的报告链接；
- 数据字段修正；
- 新品牌的公开数据；
- 筛选、排序和展示建议。

提交新数据时，请同时提供品牌公开页面或原始报告链接，方便核对和追溯。

## 说明

本项目是公开信息的整理与索引，不代表品牌方，也不对品牌进行背书。页面内容不构成医疗、营养或消费建议；若仓库数据与原始报告存在差异，请以原始报告为准。
